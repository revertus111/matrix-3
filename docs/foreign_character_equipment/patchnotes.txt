2026-10-04 - Mario helmet attachment V1
- Added `MarioEquipmentAdapter` as the first foreign-character equipment slice.
- Reads the local player's visible revision-830 helmet from decoded appearance state and loads the normal worn raw model through `ItemDefinitions.method7531(...)`.
- Preserves current gender/customization inputs, measures/normalizes the worn model once, then caches the built Matrix `Model`.
- Captures stable Mario head vertex-stream indices from the first upright libsm64 geometry frame so later animation frames can reuse the same head attachment region.
- Auto-fits helmet scale from Mario head span versus helmet worn-model span and follows the animated head translation plus native facing yaw.
- Added fit/vertical/yaw calibration system properties for the first runtime acceptance pass.
- Hooks helmet rendering immediately after a successful `MarioVisualRenderer` body pass in `Class578.method6834(...)`.
- Fail-open: missing/invalid helmet/model/attachment state never suppresses or replaces the already-working Mario body.
- Full head pitch/roll, other equipment slots, chest/leg fitting, and additional foreign-character profiles remain later bundles.

2026-10-04 - Mario live helmet calibration V3

2026-10-04 - Mario full animated head attachment V4
- Added `MarioHeadOrientationTracker` to derive a relative 3D head basis from stable top/bottom and side vertex groups inside the captured libsm64 head core.
- Helmet orientation now composes the animated head rotation delta with the accepted 180-degree reference helmet yaw, allowing yaw/pitch/roll to follow Mario's skull instead of remaining upright.
- Head attachment translation now uses the stable selected-head centroid; manual XYZ calibration is transformed through the same full head matrix so all offsets remain head-local during turns/tilts/flips.
- Uses `Class261.method3572(...)` + `method3578(...)` for full 3x3 rotation and uniform scale, with yaw-only fail-open fallback when the head basis is invalid.
- Added Matrix-visible SM64 presentation freeze in `Sm64BridgeSession`: F6 captures one immutable geometry/state snapshot while the native 30 Hz worker keeps running, and refreshes only the presentation timestamp for the existing stale-frame guard.
- F6 calibration now freezes/unfreezes Mario's visible pose in addition to freezing gameplay input; mode exit, helmet unequip and bridge stop clear the presentation freeze.
- Updated live calibration XYZ semantics to head-local axes; session values and permanent-default strategy remain unchanged.
- Mario cap/hair/skull masking is still deferred until orientation/transform runtime acceptance; face/moustache/nose remain untouched.
